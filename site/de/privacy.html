Datenschutzerklärung

Zuletzt aktualisiert am 24. September 2026

VRCVerify verknüpft ein Discord-Konto mit einem VRChat-Konto, damit ein Server auf VRChats Altersverifizierung reagieren kann. Diese Verknüpfung ist das Sensibelste hier, und diese Seite sagt genau, was gespeichert wird, wie lange und wer es sonst sieht.

Kurz gesagt. Wir speichern Ihre Discord-Benutzer-ID, Ihre VRChat-Benutzer-ID und ob VRChat Sie als altersverifiziert meldet. Wir speichern weder Ihren VRChat-Anzeigenamen noch Ihre Profilbeschreibung, Ihre E-Mail-Adresse oder Kartendaten. Nichts wird verkauft, und nichts wird für Werbung weitergegeben.

Wer wir sind#

VRCVerify wird betrieben von Esatto Technologies, Vereinigte Staaten. Für alles in dieser Richtlinie, einschließlich einer Anfrage zur Einsicht oder Löschung Ihrer Daten, schreiben Sie an contact@esattotech.com.

Was wir erheben#

Wenn Sie sich verifizieren#

DatenWozu
Ihre Discord-Benutzer-IDUm zu wissen, welches Konto sich verifiziert hat, und um die Rolle zu vergeben.
Ihre VRChat-Benutzer-ID (usr_...)Um VRChat zu fragen, ob dieses Konto altersverifiziert ist.

Sobald Sie verifiziert sind, ermöglicht die Verknüpfung Ihres Discord- und Ihres VRChat-Kontos jedem anderen Server mit VRCVerify, Sie ohne erneuten Durchlauf zu erkennen. Genau darum geht es, und deshalb bleibt der Datensatz bestehen.

Wenn ein Server den Bot nutzt#

Für jeden Discord-Server: die Server-ID, die Discord-ID des Inhabers, die konfigurierten Rollen- und Kanal-IDs, die gewählte Sprache, die Funktionseinstellungen, eine etwaige eigene Nachricht nach der Verifizierung und die Zahl der abgeschlossenen Verifizierungen. Ändert ein Administrator eine Einstellung im Dashboard, halten wir fest, wer wann was geändert hat.

Wenn ein Server per Karte abonniert#

Stripe wickelt die Zahlung ab. Wir erhalten und speichern die Stripe-Kunden-ID, die Abonnement-ID, die Preis-ID, den Abonnementstatus und das Verlängerungsdatum, damit der Bot weiß, dass der Server bezahlt hat.

Wir erhalten und speichern niemals Kartennummern, und wir speichern bewusst auch nicht die von Stripe erfasste Rechnungs-E-Mail-Adresse. Kartendaten werden auf Stripes eigenen Seiten eingegeben, nicht auf unseren.

Was wir bewusst nicht erheben#

  • Ihren VRChat-Anzeigenamen oder Ihre Profilbeschreibung. Ihre Beschreibung wird im Moment der Verifizierung gelesen, um Ihren Code zu finden, und Ihr Anzeigename wird gelesen, wenn ein Server die Spitznamen-Synchronisierung verwendet. Keines von beidem wird aufbewahrt.
  • Ihre Discord-E-Mail-Adresse, obwohl Discord sie bereitstellen könnte.
  • Den Inhalt irgendeiner Nachricht, irgendwo.
  • Karten- oder Bankdaten jeglicher Art.
  • Ausweisdokumente oder Fotos. VRChat führt die Altersprüfung durch; VRCVerify liest nur das Ja-oder-Nein-Ergebnis.

Wer sie sonst sieht#

Wir verkaufen keine personenbezogenen Daten und geben sie nicht für Werbung weiter. Verarbeitet werden die Daten von:

  • Discord — die Plattform, auf der der Bot läuft.
  • VRChat — wird gefragt, ob ein Konto altersverifiziert ist.
  • Stripe — Zahlungsabwicklung, nur für Kartenabonnements.
  • Cloudflare — liefert diese Website und das Dashboard aus.

Wir können Daten außerdem offenlegen, wo das Gesetz es verlangt.

Ihr Verifizierungsstatus ist für einen Server über die vom Bot vergebenen Rollen sichtbar, und so reagiert der Server darauf. Ein Server kann eine Rolle an Mitglieder vergeben, die VRChat als altersverifiziert meldet, und eine andere an alle, die ein VRChat-Konto verknüpft haben. Nutzt ein Server beide, zeigt der Besitz nur der zweiten Rolle, dass VRChat Sie nicht als altersverifiziert meldet. Das gilt auf jedem anderen Server mit VRCVerify, dem Sie beitreten oder auf dem Sie sich verifizieren, nicht nur auf dem, auf dem Sie sich zuerst verifiziert haben. Ein Server, der ein Verifizierungsprotokoll führt, sieht dort auch jedes Ergebnis.

Wenn ein Server die Spitznamen-Synchronisierung aktiviert, setzt der Bot Ihren Spitznamen dort auf Ihren VRChat-Anzeigenamen. Ihre VRChat-Benutzer-ID wird Serveradministratoren weder im Bot noch im Dashboard irgendwo angezeigt.

Wo sie gespeichert wird#

Die Daten werden auf Servern in den Vereinigten Staaten gespeichert. Wenn Sie sich im Vereinigten Königreich oder im Europäischen Wirtschaftsraum befinden, ist mit der Nutzung von VRCVerify eine Übermittlung Ihrer Daten in die Vereinigten Staaten verbunden.

Ihre Discord-ID, VRChat-ID und Ihr VerifizierungsstatusBis Sie uns bitten, sie zu löschen.

Ihre Rechte#

Sie können uns bitten, Ihnen die über Sie gespeicherten Daten zu zeigen, sie zu berichtigen oder zu löschen. Wenn Sie im Vereinigten Königreich oder im EWR sind, haben Sie zudem das Recht, der Verarbeitung zu widersprechen, ihre Einschränkung zu verlangen, Ihre Daten in einem übertragbaren Format zu erhalten und sich bei Ihrer örtlichen Datenschutzbehörde zu beschweren.

Um eines dieser Rechte auszuüben, schreiben Sie an contact@esattotech.com von einer Adresse, die wir Ihrem Discord-Konto zuordnen können, oder geben Sie Ihre Discord-Benutzer-ID an. Wir antworten innerhalb von 30 Tagen.

Wenn Sie Ihren Verifizierungsdatensatz löschen, müssen Sie sich erneut verifizieren, sobald ein Server das nächste Mal danach fragt.

Unsere Rechtsgrundlage, wenn Sie im Vereinigten Königreich oder im EWR sind#

  • Einwilligung für die Verifizierung selbst. Sie starten sie, und Sie können sie widerrufen, indem Sie uns bitten, den Datensatz zu löschen.
  • Vertragserfüllung für Abonnement- und Abrechnungsdaten.
  • Berechtigte Interessen für Servereinstellungen, Ratenbegrenzung sowie den sicheren und funktionierenden Betrieb des Dienstes.

Kinder#

Discord verlangt von seinen Nutzern ein Mindestalter von 13 Jahren, in einigen Ländern mehr. VRCVerify richtet sich nicht an Kinder, und wir erheben wissentlich keine Daten von Personen unterhalb des Mindestalters von Discord. Wenn Sie glauben, dass hier Daten eines Kindes gespeichert sind, schreiben Sie uns, und wir löschen sie.

Sicherheit#

Der Zugriff auf die Datenbank ist auf den Betreiber beschränkt. Das Dashboard hält keine Datenbank-Zugangsdaten und erreicht den Bot nur über eine beidseitig authentifizierte private Netzwerkverbindung, sodass eine Kompromittierung der öffentlichen Website allein die Verifizierungsdaten nicht offenlegt.

Änderungen#

Ändert sich diese Richtlinie wesentlich, aktualisieren wir das Datum oben und kündigen bedeutende Änderungen im Support-Kanal an. Wer VRCVerify nach einer Änderung weiter nutzt, akzeptiert die aktualisierte Richtlinie.
